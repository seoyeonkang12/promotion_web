## 📌 Project Overview

불꽃축제의 화려한 분위기를 시각적으로 표현하고, 방문자가 축제와 관련된 정보를 직관적으로 확인할 수 있도록 프로모션 사이트를 리디자인했습니다.

어두운 배경과 불꽃 이미지를 활용해 축제의 분위기를 강조하고, 타이포그래피와 다양한 인터랙션을 적용해 콘텐츠에 집중할 수 있도록 구성했습니다.

- **Project :** 개인 프로젝트
- **Date :** 2026.09-2026.09 (총 3일)
- **Target :** PC 화면 중심
- **Role :** 기획, UI 디자인, 퍼블리싱 및 인터랙션 구현

## 🛠️ Tech Stack

- **HTML5 :** 웹페이지 구조 및 콘텐츠 구성
- **SCSS :** 스타일 작성 및 관리
- **jQuery :** DOM 제어 및 이벤트 처리
- **GSAP :** 스크롤 기반 애니메이션 구현
- **Swiper :** 슬라이드 및 팝업 인터랙션 구현

## ✨ Key Features

### 1. Visual Design
- 어두운 배경과 불꽃 이미지를 활용한 메인 비주얼 구성
- 굵은 타이포그래피를 활용해 시각적 주목도 강화
- 축제의 분위기를 강조한 콘텐츠 레이아웃 구성

### 2. Scroll Animation
- GSAP을 활용한 스크롤 기반 애니메이션 구현
- 텍스트와 콘텐츠 요소가 순차적으로 나타나는 효과 적용

### 3. Hover Interaction
- 마우스 호버에 따른 활성 상태 변경
- 선택한 콘텐츠에 따라 배경 이미지가 변경되는 인터랙션 구현

### 4. Popup Slider
- Swiper를 활용한 슬라이드 콘텐츠 구성
- 팝업 열기 및 닫기 인터랙션 구현
